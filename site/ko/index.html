검색과 AI 답변에 맞게 사이트를 고치고, 다른 곳이 깨지지 않았음을 확인합니다

x-eo는 실제 사이트를 점검하고 레포 소스를 고친 뒤 배포 전에 빌드를 검증하는 Claude Code 플러그인입니다. 모든 항목에 증거 등급이 붙으므로 검색엔진이 문서로 밝힌 수정과 점검 도구의 점수만 올리는 수정을 구분할 수 있습니다.

사이트 소스를 레포로 관리하는 Claude Code 사용자를 위한 도구입니다. 점검만 할 때는 URL만 있으면 됩니다. AEO와 GEO는 ChatGPT, Claude, Perplexity, Google AI 개요의 답변에 사이트가 나오는 것을 말합니다.

점검 도구와 비교

일반 점검 도구x-eo
결과점수와 권고 목록같은 점수와 함께, 항목마다 근거에 따른 A·B·C 등급
사이트를 고치는 주체사용자Claude Code가 레포의 소스(빌드 결과물이 아닌 생성기)를 수정
수정 후점검을 다시 실행빌드 비교, JSON-LD 파싱, JavaScript 켬·끔 비교, 배포 후 실제 URL 재측정

사례: 214개 언어 사이트, 62점에서 90점

one-scroll-bible.com의 점수는 28점 올랐고 그중 12점이 Tier C 파일에서 나왔습니다. Tier C를 빼면 68%에서 89%로 올랐습니다.

한국어 첫 페이지는 JavaScript 없이는 본문이 비어 있었습니다. x-eo가 빌드에 사전 렌더링을 추가한 뒤 JavaScript를 실행하지 않는 크롤러가 보는 본문이 11%에서 53%로 늘었고, 브라우저 화면은 바이트 단위로 같았습니다. 점검 도구는 이 변경에 1점을 주었습니다.

설치와 첫 요청

  1. 플러그인 설치

    claude plugin marketplace add jungrok5/x-eo
claude plugin install x-eo@x-eo

  2. Claude Code에 요청

    요청 예:

    x-eo로 https://example.com 을 점검해 줘. 아직 고치지는 마.
    x-eo-fix로 Tier A 항목을 고치고 x-eo-verify로 검증해 줘.
    배포했어. 같은 도구와 버전으로 실제 URL을 다시 측정해 줘.

플러그인 기능을 쓰지 않으려면 스킬을 직접 복사합니다.

git clone --depth 1 https://github.com/jungrok5/x-eo.git
mkdir -p ~/.claude/skills && cp -r x-eo/plugins/x-eo/skills/* ~/.claude/skills/

bash, git, python3 3.10 이상이 필요합니다. 렌더 비교에는 playwright-core와 Chromium이 추가로 필요합니다. 인용 표본 검사만 Anthropic 또는 OpenAI API 키가 필요하고 나머지는 키 없이 실행됩니다.

증거 등급

Google의 AI 최적화 안내(2026-07-10 갱신)는 Google 검색이 AI용 텍스트 파일과 특수 마크업을 무시한다고 밝히지만, 점검 도구는 이 항목에도 다른 항목과 같이 점수를 줍니다. x-eo는 이 점수를 Tier C로 따로 보고하고 성과로 계산하지 않습니다.

자주 묻는 질문

x-eo가 사이트를 스스로 바꿉니까?

아닙니다. 스킬은 Claude Code에 요청할 때만 동작합니다. x-eo-fix가 고친 레포 소스는 배포해야 실제 사이트에 반영됩니다. 훅이나 백그라운드 에이전트는 없습니다.

API 키가 필요합니까?

ai-recall.mjs에만 필요합니다. Anthropic 또는 OpenAI 키가 필요하고 질문과 엔진마다 검색 요청 1회 비용이 발생합니다. 점검, 수정, 검증 스크립트는 키 없이 실행됩니다.

점수가 오르면 방문자가 늘어납니까?

반드시 그렇지는 않습니다. 점수는 한 도구의 가중치를 따르므로 x-eo는 Tier C 포함 점수와 제외 점수를 함께 보고합니다. AI 엔진이 페이지를 인용하는지는 표본으로만 확인합니다(ai-recall.mjs).

Claude Code 없이도 쓸 수 있습니까?

스크립트는 단독으로 실행됩니다(아래 개발자용 항목 참고). 다만 어떤 항목을 어떻게 고칠지 정하고 적용하는 부분은 Claude Code가 맡습니다.

한계

  • 등급은 키워드 규칙으로 매깁니다. 틀릴 수 있으므로 항목 내용을 직접 확인합니다.
  • 점수는 한 도구의 분류와 가중치를 따릅니다. 같은 도구, 같은 버전의 변경 전후를 비교합니다.
  • 인용 검사는 표본이며 비율이 아닙니다. 실행할 때마다 답이 달라지고 Perplexity는 지원하지 않습니다.
  • 리눅스에서만 시험했습니다. 증거 기록과 한국 가이드에는 작성 날짜가 있으므로 사용 전에 다시 확인합니다.

스킬 4개, 스크립트, 에이전트 없이 실행하는 방법
스킬스크립트

x-eo-fixgen-robots.py, JSON-LD 템플릿, 하위 경로 사이트용 루트 파일, html-to-llms-full.mjs, gen-ai-files.mjs, indexnow.mjs
x-eo-verifydiff-builds.sh, jsonld-lint.py, render-diff.mjs, local-audit.py

스크립트 직접 실행:

S=x-eo/plugins/x-eo/skills
bash    $S/x-eo-audit/scripts/audit.sh --threshold 80 https://example.com/
bash    $S/x-eo-audit/scripts/host-root-check.sh https://example.com/blog/
python3 $S/x-eo-audit/scripts/site-sample.py https://example.com/ --max 8 --fail-on A
node    $S/x-eo-verify/scripts/render-diff.mjs https://example.com/
python3 $S/x-eo-verify/scripts/jsonld-lint.py ./dist --require WebSite --strict
python3 $S/x-eo-fix/scripts/gen-robots.py --sitemap https://example.com/sitemap.xml --out robots.txt
