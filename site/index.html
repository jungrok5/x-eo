Fix your site for search and AI answers, and prove nothing else broke

Audit tools give you a score and a to-do list. x-eo is a Claude Code plugin that works through the list in your repository, then checks the build before you deploy. Each recommendation says how strong the evidence behind it is, so you do not spend time on points no search engine uses.

For Claude Code users whose site source is in a repository. Auditing alone needs only a URL. SEO is classic search, AEO and GEO are answers in ChatGPT, Claude, Perplexity and Google AI Overviews.

Example: a 214-language site, 62 to 90

x-eo was run on one-scroll-bible.com. The score rose by 28 points; 12 of them were Tier C. Without those, it moved from 68% to 89%.

The change that mattered most did not show up in the score as much: the Korean home page had no text without JavaScript. After x-eo added a prerender step, a crawler that does not run JavaScript sees 53% of the page instead of 11%, and the page in a browser stayed byte-identical.

Start in two steps

  1. Install the plugin

    claude plugin marketplace add jungrok5/x-eo
claude plugin install x-eo@x-eo

  2. Ask Claude Code

    Typical requests:

    Audit https://example.com with x-eo. Do not change anything yet.
    Fix the Tier A findings with x-eo-fix, then verify with x-eo-verify.
    We deployed. Re-measure the live URL with the same tool and version.

Without the plugin system, copy the skills directly:

git clone --depth 1 https://github.com/jungrok5/x-eo.git
mkdir -p ~/.claude/skills && cp -r x-eo/plugins/x-eo/skills/* ~/.claude/skills/

Needs bash, git and python3 3.10+. The render check also needs playwright-core and Chromium. Citation sampling needs an Anthropic or OpenAI API key; everything else runs without keys.

Why the recommendations can be trusted

Google's AI optimization guide (updated 2026-07-10) says Google Search ignores AI text files and special markup. Audit tools still score them. x-eo labels every finding by the evidence behind it and never counts Tier C as a result.

ADocumented or directly observable
The page loads, its text is in the HTML without JavaScript, canonical and hreflang are right, the sitemap is valid, JSON-LD parses and matches the page.
Fix first.
BSupported only by third-party studies
Answer-shaped paragraphs, freshness, a consistent entity name with sameAs, original data.
Do it when it also helps readers.
CConvention without demonstrated use
llms.txt, ai.txt, /ai/*.json, WebMCP.
Only if free. Never counted as a result.
SECSecurity
A place where third-party text reaches crawlers, an exposed secret.
Confirm a real write path before reporting.

Questions

Does x-eo change my site on its own?

No. The skills act only when you ask Claude Code. x-eo-fix edits the source in your repository, and nothing goes live until you deploy. There is no hook or background agent.

Do I need an API key?

Only for ai-recall.mjs, which needs an Anthropic or OpenAI key and costs one search-enabled request per question and engine. The audit, fix and verify scripts run without keys.

Will a higher score bring more visitors?

Not necessarily. The score follows one tool's weights, and Google says it ignores AI text files. That is why x-eo reports the score with and without Tier C points, and why citation by AI engines is only sampled.

Does it work without Claude Code?

The scripts run on their own (see the developer section below), but choosing and applying fixes is the part Claude Code does.

Limits

  • Tier labels come from keyword rules. A label can be wrong; read the finding.
  • Scores come from one tool and its author's weights. Compare the same tool and version before and after.
  • Citation sampling is a sample, not a rate. Answers vary between runs; Perplexity is not covered.
  • Tested on Linux. The evidence ledger and the Korea guide are dated; check them again before relying on them.

For developers: what is inside

Four skills, the scripts, and how to run them without an agent
SkillScripts
x-eo-auditaudit.sh (score with and without Tier C, --threshold for CI), host-root-check.sh, site-sample.py, ai-recall.mjs
x-eo-fixgen-robots.py, JSON-LD templates, root files for sub-path sites, html-to-llms-full.mjs, gen-ai-files.mjs, indexnow.mjs
x-eo-verifydiff-builds.sh, jsonld-lint.py, render-diff.mjs, local-audit.py

Run the scripts directly:

S=x-eo/plugins/x-eo/skills
bash    $S/x-eo-audit/scripts/audit.sh --threshold 80 https://example.com/
bash    $S/x-eo-audit/scripts/host-root-check.sh https://example.com/blog/
python3 $S/x-eo-audit/scripts/site-sample.py https://example.com/ --max 8 --fail-on A
node    $S/x-eo-verify/scripts/render-diff.mjs https://example.com/
python3 $S/x-eo-verify/scripts/jsonld-lint.py ./dist --require WebSite --strict
python3 $S/x-eo-fix/scripts/gen-robots.py --sitemap https://example.com/sitemap.xml --out robots.txt
